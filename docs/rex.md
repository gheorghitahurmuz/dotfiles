# Rex

Themes: `~/.config/rex/themes`.

Rex does not read theme files from disk. Import each file once from Settings →
Import Theme; Rex matches it to the light or dark appearance by background
color and stores a copy in its own preferences. Re-import after changing a file.

- `Night Owl`: dark appearance.
- `Night Owlish Light`: light appearance.

The [iTerm2 Color Schemes](https://github.com/mbadolato/iTerm2-Color-Schemes/tree/master/ghostty)
Ghostty exports provide both files unchanged.
